> If you are reading this by opening the file in the folder of downloaded LC Localization Interface, this description is intended for the Github repository of [\[⇲\] Assets Directory](https://github.com/x1bViolet/LCLI-Assets-Directory).


This repository represents the `[⇲] Assets Directory` folder included with [LC Localization Interface](https://github.com/x1bViolet/Limbus-Localization-UI) program in its releases.

This folder contains asset files required for [LC Localization Interface](https://github.com/x1bViolet/Limbus-Localization-UI) to work, as well as additional resources. Users of the [LC Localization Interface](https://github.com/x1bViolet/Limbus-Localization-UI) can receive resource updates for their folder via `git pull` or [GitHub Desktop](https://desktop.github.com/download/) whenever the contents of this repository are updated.
